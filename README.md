### ⚡ About Me

- 🎓 **Education:** 3rd Year BS Computer Science student at **Batangas State University** (Calamba / Batangas, PH).
- 💻 **What I Build:** 
  - Fast, intentional web applications and storefronts with **Next.js**, **TypeScript**, and **Tailwind CSS**.
  - AI-integrated desktop and productivity tools with **C# (.NET 8)** and **WinForms** (like [*KORY*](https://github.com/Sh1do-o), an academic Gmail assistant with Gemini reply scoring).
  - Data-driven apps and recommendation engines (like [*MangaMatch*](https://github.com/Sh1do-o), a manga tracker leveraging Gemini & AniList APIs).
- 🚀 **What I Want to Build:**
  - Deep-dive applications in **Data Science & Machine Learning**.
  - Intelligent multi-agent developer tools and full-stack AI platforms.
  - Expressive, interactive UI experiments with smooth motion and animation.
- 🎯 **Current Focus:** Sharpening data analysis pipelines, full-stack architecture, and exploring backend systems.
- 🎮 **Offline:** Playing games, hitting the court/gym, reading manga, or tinkering with hardware.
